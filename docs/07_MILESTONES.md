# Milestones (proposed sequence)
1. Team tools and assignments confirmed.
2. Electrical safety reviewed and first motor/controller selected.
3. One safe motor/joint with repeatable movements.
4. ADXL345 and DS18B20 basic readings.
5. Mock, then actual telemetry from ESP32 to Python and simple dashboard.
6. Log healthy baselines, and only teacher-approved safe fault cases.
7. Basic threshold/rule detection and validation.
8. More complex arm and optional IsolationForest only when justified by repeatable data.

Every milestone starts as **not verified** until test evidence is linked.
